# Asset

## Назначение

Asset представляет учебный ресурс, который может использоваться
в одном или нескольких заданиях.

Asset является самостоятельной сущностью системы.

Asset существует независимо от уроков,
этапов и заданий.

Удаление урока не приводит к удалению Asset.

---

# Ответственность

Asset отвечает только за описание учебного ресурса.

Asset хранит информацию,
необходимую для идентификации и отображения ресурса.

Asset не знает,
как используется данный ресурс.

---

# Что знает Asset

Asset хранит:

- id;
- тип ресурса;
- источник;
- путь к данным;
- паспорт;
- миниатюру;
- название;
- категорию;
- теги;
- размеры;
- дополнительные метаданные.

---

# Что НЕ знает Asset

Asset не знает:

- в каких уроках используется;
- в каких Stage используется;
- в каких Task используется;
- кто решал ресурс;
- результаты студентов;
- статистику использования;
- параметры уроков;
- параметры проверки.

---

# Связи

Asset является независимой сущностью.

Asset не принадлежит Lesson.

Asset не принадлежит Stage.

Asset не принадлежит Task.

На Asset могут ссылаться множество AssetRef.

                Asset
                  ▲
                  │
        ┌─────────┼─────────┐
        │         │         │
    AssetRef  AssetRef  AssetRef

---

# Жизненный цикл

Asset создаётся средствами формирования базы данных.

Asset сохраняется в Dataset.

Asset может использоваться
в любом количестве уроков.

Asset никогда не копируется
при создании Lesson.

---

# Основные типы Asset

Проект должен поддерживать различные виды ресурсов.

Например:

- Nonogram
- Image
- Photo
- Video
- Audio
- Text
- PDF
- HTML
- Dataset

Список открыт для расширения.

Для первой версии проекта
основным типом является

Nonogram.

# Использование Passport

Для японских кроссвордов Asset использует Passport.

Passport содержит описание учебного материала.

Например:

- размеры;
- категория;
- автор;
- сложность;
- признаки изображения;
- исследовательские параметры.

Asset не изменяет Passport.

Passport формируется средствами PassportDatabase.

---

# Использование Renderer

Миниатюра Asset
генерируется существующим Renderer.

Asset не выполняет рендеринг самостоятельно.

---

# Что не делает Asset

Asset не открывает окно.

Asset не отображает изображение.

Asset не выполняет поиск.

Asset не знает,
какой урок сейчас открыт.

Asset не взаимодействует со студентом.

Asset не хранит ответы студентов.

Asset не выполняет проверку решения.

# Архитектурные правила

Asset является независимым объектом.

Asset не принадлежит Lesson.

Asset может использоваться
неограниченным количеством уроков.

Asset никогда не содержит
данные конкретного студента.

Asset не изменяется
во время выполнения урока.

Единственным источником изменения Asset
является PassportDatabase.

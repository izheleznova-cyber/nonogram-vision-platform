# Rubric

## Назначение

Rubric описывает правила оценивания урока.

Rubric определяет,
как вычисляется итоговая оценка
по результатам выполнения урока.

Rubric не хранит результаты студентов.

Rubric не выполняет вычисления.

---

# Ответственность

Rubric отвечает только за описание системы оценивания.

Rubric определяет:

- критерии оценки;
- веса критериев;
- шкалу оценивания;
- правила вычисления итогового результата.

---

# Что знает Rubric

Rubric хранит:

- id;
- название;
- описание;
- режим оценивания;
- список Criterion;
- максимальный балл;
- правила подсчёта.

---

# Что НЕ знает Rubric

Rubric не знает:

- ответы студентов;
- текущий прогресс;
- результаты проверки;
- оценки конкретного студента;
- статистику выполнения.

---

# Связи

Rubric принадлежит Lesson.

Lesson
    │
    ▼
Rubric
    │
    ▼
Criterion[]

Rubric не принадлежит Stage.

Rubric не принадлежит Task.

---

# Жизненный цикл

Rubric создаётся Lesson Designer.

Rubric сохраняется
в manifest урока.

Monitor использует Rubric
при вычислении итоговой оценки.

Student Platform
не изменяет Rubric.

---

# Что определяет Rubric

Rubric описывает,
какие критерии используются
при оценке урока.

Например

- правильность решения;
- время выполнения;
- количество попыток;
- выполнение обязательных заданий;
- качество прогнозирования;
- качество профайлинга.

# Criterion

Criterion представляет
один критерий оценивания.

Например

- Решение кроссворда
- Определение объекта
- Определение эмоции
- Определение автора
- Качество гипотез

Каждый Criterion имеет собственный вес.

---

# Возможные режимы оценивания

Pass / Fail

Зачёт / Незачёт

---

Points

Сумма баллов.

---

Weighted

Взвешенная сумма критериев.

---

Percentage

Процент выполнения.

---

Research

Результаты используются
только для исследования.

Итоговая оценка не вычисляется.

---

# Что не делает Rubric

Rubric не проверяет ответы.

Rubric не вычисляет баллы.

Rubric не анализирует ошибки.

Rubric не взаимодействует
со Student Platform.

Rubric не хранит статистику студентов.

# Архитектурные правила

Rubric является описанием
системы оценивания.

Алгоритмы вычисления
принадлежат Monitor.

Lesson Designer
описывает правила оценки.

Monitor
применяет эти правила.

# Главное правило

Rubric описывает,
как должен оцениваться урок.

Rubric не хранит результаты студентов.

Rubric не вычисляет итоговую оценку.

Rubric является частью Lesson Designer.

Monitor использует Rubric для вычисления итогового результата.

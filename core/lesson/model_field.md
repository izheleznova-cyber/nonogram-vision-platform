# Lesson Model Fields

## Назначение

Документ определяет минимальный обязательный набор полей каждой модели Lesson Designer.

Указываются только обязательные поля.

Необязательные параметры будут добавляться позднее по мере развития проекта.

---

# Lesson

Минимальный набор полей

```python
id
title
stages
rubric (None)
```

Описание

id

Уникальный идентификатор урока.

title

Название урока.

stages

Список Stage.

rubric

Правила оценивания.

---

---

# Главное правило

Все модели начинаются с минимального набора обязательных полей.

Новые поля добавляются только при появлении новой функциональности.

Не допускается добавление полей "на будущее".

# Task

## Назначение

Task описывает одно учебное действие, которое должен выполнить студент.

Task является минимальной учебной единицей Lesson Designer.

Task не хранит состояние выполнения.

Task не зависит от конкретного студента.

---

# Ответственность

Task отвечает только за описание задания.

Task определяет:

- что должен сделать студент;
- какой ресурс использовать;
- какой ожидается результат;
- как проверяется выполнение.

Task не выполняет проверку.

Task не хранит результаты проверки.

---

# Что знает Task

Task хранит:

- id;
- название;
- описание;
- тип задания;
- инструкцию студенту;
- параметры задания;
- ссылку на учебный ресурс (AssetRef);
- спецификацию ответа (AnswerSpec);
- максимальный балл;
- необязательные подсказки.

---

# Что НЕ знает Task

Task не знает:

- кто выполняет задание;
- сколько студентов уже выполнили задание;
- сколько попыток сделал студент;
- время решения;
- историю прохождения;
- текущий статус выполнения;
- полученные баллы;
- ошибки проверки.

Эти данные относятся к Monitor.

---

# Связи

Task принадлежит одному Stage.

Stage
    ↓
Task

Task использует

AssetRef

Task использует

AnswerSpec

Task не содержит Asset.

Task не содержит StudentProgress.

---

# Жизненный цикл

Task создаётся Lesson Designer.

Task сохраняется в manifest урока.

Task читается Monitor.

Task выполняется Student Platform.

Task никогда не изменяется Student Platform.

---

# Что не делает Task

Task не открывает файл.

Task не загружает изображения.

Task не выполняет проверку.

Task не вычисляет оценки.

Task не хранит результаты студентов.

Task не взаимодействует с PassportDatabase.

---

# Возможные типы Task

Проект должен позволять добавлять новые виды заданий.

Например:

- SolveNonogram
- PredictObject
- PredictAuthor
- FaceProfiling
- EmotionRecognition
- AgeRecognition
- GenderRecognition
- MultipleChoice
- FreeTextAnswer

Список открыт для расширения.

---

# Использование AssetRef

Task никогда не хранит ресурс напрямую.

Task содержит только ссылку:

Task
    ↓
AssetRef
    ↓
Asset

Это позволяет использовать один Asset
в разных уроках без копирования данных.

---

# Использование AnswerSpec

Task не знает,
как именно проверяется ответ.

Task содержит только описание ожидаемого результата.

Проверкой занимается Monitor.

---

---

# Архитектурные правила

Task является неизменяемым описанием задания.

Task не содержит состояние выполнения.

Task не знает ничего о конкретном студенте.

Task может использоваться многократно
в разных уроках.

Task расширяется добавлением новых типов заданий,
а не изменением существующих.
